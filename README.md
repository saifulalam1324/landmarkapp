# 🏛️ Landmark Recognition App

A Flutter-based mobile application that identifies landmarks from images using a trained machine learning model. Users can select an image from their gallery or capture a photo using their device camera to receive a landmark prediction.

## 📌 Project Overview

The **Landmark Recognition App** is a collaborative project between the **Research Team** and the **Mobile App Development Team**.

The Research Team developed and trained the landmark recognition model and provided the trained model to the Mobile App Development Team. The Mobile App Development Team was responsible for building the Flutter mobile application, designing the user interface, integrating the API and connecting the application to the trained model for landmark prediction.

The goal is to provide users with a simple and user-friendly way to recognize landmarks through images.

## ✨ Features

* 📷 Capture landmark images using the device camera.
* 🖼️ Select landmark images from the device gallery.
* 🤖 Recognize landmarks using the trained machine learning model.
* 🔗 Integrate the mobile application with the prediction API.
* ⏳ Display loading indicators while processing images.
* 📊 Display prediction results returned by the model API.
* 📱 Build a mobile interface using Flutter.

## 👥 Team Collaboration

This project was completed through collaboration between two teams.

### 1. Research Team

**Primary responsibility: Machine Learning Research and Model Development**

* Collected and prepared the landmark image dataset.
* Performed data preprocessing and model training.
* Developed and evaluated the landmark recognition model.
* Provided the trained model to the Mobile App Development Team for integration.

2. Mobile App Development Team

Primary responsibility: Flutter Application Development and Model Integration

The mobile team consisted of three members with separate responsibilities.

Team Member Role	Responsibilities
UI Developer 1	Developed the mobile application's user interface and screen layouts.
UI Developer 2	Worked on UI components, image selection screens and improving the user experience.
API Integration Developer	Integrated the prediction API with Flutter, handled image uploads and API responses, and connected the mobile application to the trained model.
